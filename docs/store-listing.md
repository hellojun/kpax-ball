## Detailed Description

KPAX Ball brings AI-powered football analysis directly to your Polymarket browsing experience.

**How it works:**
1. Browse any football match on Polymarket
2. Click "Game View" to enter a specific match
3. KPAX Ball automatically detects the match and shows analysis in the sidebar

**Features:**

Quick Analysis (~5 seconds)
- AI-generated probability assessment
- Side-by-side odds comparison (Market vs KPAX)
- Confidence rating with reasoning
- Works for Premier League, Chinese Super League, Copa Sudamericana, and more

Deep Analysis (~2-3 minutes)
- Multi-expert AI debate with 4 specialized analysts:
  - Tactical Network Analyst
  - Statistical Modeler
  - Tactical Interpreter
  - Psychological Context Analyst
- Structured final report with key variables and expert disagreements
- Follow-up questions for deeper exploration

Additional Features:
- Real match data from API-Football (standings, H2H, form)
- Knowledge graph visualization
- Bilingual support (English / Chinese)
- Dark/light theme synced with Polymarket
- Google Sign-In for secure access

**Important:** KPAX Ball is an analysis tool for informational purposes only. It does not provide financial advice or trading recommendations.
